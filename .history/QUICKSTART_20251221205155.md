## Inférence sur Nouvelle Trajectoire

```python
import numpy as np
import pickle
from tensorflow import keras
from hit_n_bounce.cnn_lstm_detector import (
    TimeSeriesWindowDataset,
    extract_raw_features,
    EventPostProcessor
)
from hit_n_bounce.features import FeatureConfig, compute_kinematics

# 1. Charger le modèle entraîné
model = keras.models.load_model(
    'models/cnn_lstm_tennis_events.keras',
    custom_objects={'FocalLoss': FocalLoss}
)

with open('models/feature_scaler.pkl', 'rb') as f:
    scaler = pickle.load(f)

# 2. Préparer les données
cfg = FeatureConfig(fps=50.0)
frames = np.arange(200)
xs = [...]  # Vos coordonnées X
ys = [...]  # Vos coordonnées Y

# 3. Pipeline de prédiction
kin = compute_kinematics(frames, xs, ys, cfg)
X_raw, _ = extract_raw_features(kin)

windower = TimeSeriesWindowDataset(window_size=31)
X_windows, _, _ = windower.create_windows(
    X_raw, 
    np.zeros(len(X_raw))  # Labels fictifs
)

X_scaled = scaler.transform(
    X_windows.reshape(-1, 9)
).reshape(X_windows.shape)

# 4. Prédiction
y_proba = model.predict(X_scaled)

# 5. Post-processing NMS
post_processor = EventPostProcessor(
    confidence_threshold=0.5,
    min_event_distance=10
)

detections = post_processor.extract_events(
    y_proba,
    threshold_hit=0.5,
    threshold_bounce=0.5
)

# 6. Résultats
print(f"Hits détectés: {len(detections['hits'])}")
for frame, conf in detections['hits']:
    print(f"  Frame {frame}: {conf:.3f}")

print(f"Bounces détectés: {len(detections['bounces'])}")
for frame, conf in detections['bounces']:
    print(f"  Frame {frame}: {conf:.3f}")
```

## Visualisation des Détections

```python
# Visualiser les probabilités
import matplotlib.pyplot as plt

fig, axes = plt.subplots(3, 1, figsize=(15, 8), sharex=True)
frames_idx = np.arange(len(y_proba))

labels = ['Air', 'Hit', 'Bounce']
colors = ['gray', 'red', 'blue']

for i, (ax, label, color) in enumerate(zip(axes, labels, colors)):
    ax.plot(frames_idx, y_proba[:, i], label=f'P({label})', 
           color=color, linewidth=2)
    
    # Marquer les détections
    if i == 1:  # Hits
        for frame, conf in detections['hits']:
            ax.axvline(frame, color='red', alpha=0.5, linestyle='--')
            ax.scatter(frame, conf, color='red', s=200, 
                      marker='*', edgecolors='black', zorder=5)
    elif i == 2:  # Bounces
        for frame, conf in detections['bounces']:
            ax.axvline(frame, color='blue', alpha=0.5, linestyle='--')
            ax.scatter(frame, conf, color='blue', s=200, 
                      marker='*', edgecolors='black', zorder=5)
    
    ax.set_ylabel(f'P({label})')
    ax.legend()
    ax.grid(True, alpha=0.3)

axes[-1].set_xlabel('Frame')
plt.tight_layout()
plt.savefig('predictions.png', dpi=150)
```

## Debugging & Troubleshooting

### Erreur : "TensorFlow non disponible"
```bash
pip install --upgrade tensorflow
# ou pour GPU :
pip install tensorflow-gpu
```

### Erreur : "Out of Memory"
Réduire `batch_size` :
```python
model, results = run_cnn_lstm_pipeline(
    cfg=cfg,
    batch_size=64,  # ← Réduit de 256 à 64
    ...
)
```

### Le modèle ne converge pas (loss plateau)
1. **Vérifier les données** :
```python
print(f"Distribution: {np.bincount(y_all)}")
# Doit montrer des événements (Hit/Bounce)
```

2. **Réduire le learning rate** :
```python
model.compile(
    optimizer=keras.optimizers.Adam(learning_rate=0.0001),  # ← Réduit
    loss=loss_fn,
    metrics=[...]
)
```

3. **Augmenter la patience** :
```python
keras.callbacks.EarlyStopping(
    monitor='val_loss',
    patience=25,  # ← Augmenté de 15 à 25
    restore_best_weights=True
)
```

### F1-Score trop faible sur événements
1. **Ajuster alpha dans Focal Loss** :
```python
# Favoriser encore plus les événements
loss = FocalLoss(alpha=[0.02, 0.49, 0.49], gamma=2.5)
```

2. **Augmenter window_size** :
```python
model, results = run_cnn_lstm_pipeline(
    window_size=51,  # ← 51 au lieu de 31
    ...
)
```

3. **Data augmentation** :
```python
windower = TimeSeriesWindowDataset(window_size=31)
X_aug, y_aug = windower.create_augmented_windows(
    X_raw, y, augmentation_factor=5  # ← 5x plus d'événements
)
```
